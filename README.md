# [自訂題庫測驗v1.0](https://yuu0w0-1009.github.io/customized_quiz/)
**中文** ｜ [English](README.en.md)

一個純前端的「自訂題庫測驗」靜態網站

**零依賴、免安裝、免後端**，只要上傳一個 JSON 題庫檔就能立刻開始測驗

---
## 主功能說明
1. 可自訂題庫
2. 打亂題目
3. 答題進度追蹤
4. 結果統計
5. 錯誤檢視

## 題庫 JSON 格式

### 結構

```json
{
  "題目數": 1,
  "題目": [
    {
      "題號": 1,
      "題目": "已知 a = 1、b = 2，則 a + b = ?",
      "A": "1",
      "B": "2",
      "C": "3",
      "D": "4",
      "答案": "C",
      "詳解": "將 a = 1 與 b = 2 相加，1 + 2 = 3，故選 C。"
    }
  ]
}
```

### 欄位說明

| 欄位 | 必要性 | 說明 |
| --- | --- | --- |
| `題目數` | 選填 | 僅供參考；實際總題數以 `題目` 陣列的長度為準 |
| `題目` | **必填** | 題目物件陣列，不可為空 |
| `題號` | 選填 | 未提供時自動以 1、2、3… 編號 |
| `題目` | **必填** | 題目文字 |
| `A` / `B` / `C` / `D` | **必填** | 四個選項的文字內容 |
| `答案` | **必填** | 正確選項，填 `A`、`B`、`C` 或 `D`（不分大小寫） |
| `詳解` | 選填 | 詳解文字，未提供時顯示「（無提供詳解）」 |

### 相容性

以下欄位別名皆可被辨識，方便沿用既有題庫：

- `題目`：`題目`、`题目`、`question`、`title`
- 選項：`A` / `a` / `選項A`（B、C、D 同理）
- `答案`：`答案`、`answer`
- `詳解`：`詳解`、`详解`、`解析`、`explanation`
- `題號`：`題號`、`题号`、`id`、`no`

檔案內容若含有 BOM（`\uFEFF`）字元，會自動移除後再解析。詳解中的換行可用 `\n` 表示，顯示時會保留換行。

## 使用流程

```
檔案讀取頁
  └─ 選擇／拖拽 .json 檔 → 驗證通過 → 顯示總題數 → 開始測驗
       └─ 答題頁（單題切換，可勾選打亂題目）
            └─ 交卷（有未作答題目時彈出確認視窗）
                 └─ 結果結算頁（正確率、錯題清單）
                      ├─ 觀看全部詳解 → 逐題檢視 → 結束 → 回結果頁
                      ├─ 重新開始答題（保留題庫，重新作答）
                      └─ 從頭開始（清空全部狀態）
```

---

## 操作小技巧

- 選項可以重複點擊來**取消選取**，讓該題回到未作答狀態。
- 打亂題目後，畫面上的題號是「測驗中的第幾題」，與 JSON 中的原始 `題號` 無關。
- 「重新開始答題」不會重新讀取檔案，適合把同一份題庫再練一次。
